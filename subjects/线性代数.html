行列式的定义与基本性质 ​

掌握度: 50% | 创建: 2026-09-15 | 最近复习: 2026-09-15

掌握度进度: █████░░░░░

核心内容:

行列式=按固定规则把 n×n 个数算成的一个数(不是矩阵)。2阶:|a b; c d| = ad-bc。3阶:对角线法则(沙路法)——主对角线三乘积之和 减 副对角线三乘积之和;更高阶:按某一行(列)展开,元素×代数余子式再求和。高频性质:①交换两行(列),值变号;②某行(列)全部乘 k,值乘 k(故可提公因子);③两行相同或成比例,值为 0;④某行乘 k 加到另一行,值不变(化简主力,把行列式化上三角再对角相乘)。考察方式:数值计算、含参行列式、用性质判 0、与方程组/特征值联动。

💡 点击展示例题答案

例:求 |2 1; 3 4|。解:=2×4-1×3=5。验算性质①:交换两行得 |3 4; 2 1| = 3×1-4×2 = -5,恰为原值变号,性质①成立。再例:|1 2 3; 4 5 6; 7 8 9|:因第1行+第3行=(8,10,12)=2×第2行,三行线性相关 → 值为 0(性质③)。

行列式的计算:化三角形法与展开定理 ​

掌握度: 50% | 创建: 2026-09-22 | 最近复习: 2026-09-22

掌握度进度: █████░░░░░

核心内容:

行列式求值两条主线:①化三角形法——用性质④(某行加另一行的 k 倍,值不变)把主对角线下方元素全部化为 0,则行列式 = 主对角线元素连乘;②按行(列)展开——|A| = Σ a_ij·A_ij,代数余子式 A_ij = (-1)^(i+j)·M_ij,挑含 0 最多的行(列)展开最省算。三条铁律(易错):(a) 化简只能用「某行加另一行的倍数」(值不变),不能先「某行乘 k」再消元——那样值被改动,必须补偿;(b) 交换两行(列)要记 -1;(c) 上三角/下三角/对角行列式 = 主对角线乘积,这是化三角形法的收尾依据。自我复核:算完再按另一行展开验一遍,或看是否满足性质③(两行成比例则值为 0)。考研考法:含参行列式计算、抽象行列式用性质变形、与 |AB|=|A||B|、|kA|=k^n|A| 联动。

💡 点击展示例题答案

例:计算 D = |1 2 3; 2 5 7; 3 7 11|。解:r2-2r1 → (0,1,1);r3-3r1 → (0,1,2),得 |1 2 3; 0 1 1; 0 1 2|;再 r3-r2 → (0,0,1),上三角 D = 1×1×1 = 1。复核(按第 1 行展开)😄 = 1×(5×11-7×7) - 2×(2×11-7×3) + 3×(2×7-5×3) = 6 - 2 - 3 = 1,与化三角形结果一致。
